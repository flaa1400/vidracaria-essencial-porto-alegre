# Vidro Essencial Porto Alegre 💎

Este é o repositório oficial do novo site da **Vidro Essencial Porto Alegre**, uma vidraçaria de elite especializada em soluções premium para residências e estabelecimentos comerciais. O projeto foi desenvolvido com foco total em **SEO Local de alta performance** e conversão de leads.

## 🚀 Status: Pronto para Produção

O site está finalizado, otimizado e configurado para deploy imediato via Vercel.

## ✨ Diferenciais do Projeto

- **SEO Local Dominante:** Estrutura de silos com 32 páginas exclusivas para os principais bairros de Porto Alegre.
- **Estratégia Long-tail:** Geração dinâmica de mais de 480 páginas de serviços localizados (ex: "Box de Banheiro em Belém Novo em Porto Alegre").
- **Design de Elite:** Interface moderna, responsiva e focada em luxo, utilizando Tailwind CSS e Astro.
- **Alta Conversão:** Integração direta com WhatsApp e formulários de contato profissionais (Web3Forms).
- **Performance Extrema:** Construído com Astro para garantir carregamento instantâneo e pontuação máxima no Core Web Vitals.

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Astro](https://astro.build/) (Modo SSR com Adaptador Vercel)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Linguagem:** TypeScript
- **Conteúdo:** Markdown & Content Collections
- **SEO:** Schema.org (JSON-LD), Sitemap dinâmico e Meta-tags otimizadas
- **Infraestrutura:** Git & Vercel

## 📦 Como rodar localmente

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Acesse: `http://localhost:4321`
